## English (Secondary)

### App Name
CashVision — Banknote Checker

### Subtitle
Recognize and count banknotes

### Description
CashVision helps you verify the security features of Russian banknotes using your iPhone camera.

Features:
• Real-time banknote denomination recognition
• Interactive hints for security features (watermark, security thread, microperforation, relief, hologram, etc.)
• Multi-banknote counting mode with running total
• Local-only history of operations
• Full Dark Mode and VoiceOver support
• Privacy-first: images stay on your device

Important: the app helps you visually inspect banknote features and does NOT guarantee authenticity. For final verification, use the official Bank of Russia verification method.
